# MathCraft

Jogo de Matemática do dia a dia, feito em **HTML, CSS e JavaScript**, sem bibliotecas e **funcionando offline** (um único arquivo).

Protótipo criado para o projeto de extensão **Fábrica de Software Itinerante** (Análise e Desenvolvimento de Sistemas, UNINASSAU Boa Viagem), apresentado em um workshop de gamificação para estudantes do Ensino Médio (EJA).

## Como jogar

1. Baixe o arquivo `MathCraft.html`.
2. Dê dois cliques para abrir no navegador. Não precisa de internet.
3. Digite seu nome (ou o da equipe), escolha um tema e responda 8 perguntas.

## O que o jogo tem

- **4 temas:** Desconto, Troco, Conta de luz e Velocidade (ou todos misturados).
- **Perguntas sorteadas:** os números mudam a cada partida, com dificuldade crescente (3 níveis).
- **Gamificação:** pontos, bônus por sequência de acertos, dicas (que custam pontos), badges e ranking local.
- **Aprendizado:** depois de cada resposta, certa ou errada, o jogo explica como fazer a conta passo a passo e mostra um truque para fazer de cabeça.

## Tecnologias

HTML5, CSS3 e JavaScript puro (sem frameworks). O ranking usa `localStorage` do navegador.
