Como o código sorteia uma pergunta

Este é o trecho de JavaScript que cria uma pergunta de desconto. Cada vez que você joga, os números mudam.

function desconto() {
  const preco = sortear([40, 60, 80, 120]);
  const pct   = sortear([10, 20, 25, 50]);
  const economia = preco * pct / 100;
  return {
    texto: `Uma camiseta custa R$ ${preco} e está
            com ${pct}% de desconto. Quanto você paga?`,
    resposta: preco - economia
  };
}
